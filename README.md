# LAW / INDEX

法務関連の記事・一次資料を、原文へ進むための情報として整理する静的アーカイブです。

## 含まれる機能

- 今日追加された記事の代表表示
- フリーワード検索、分野、資料種別、テーマでの絞り込み
- 追加日・公開日・重要度での並び替え
- 未読 / 保存済み / 一次資料の表示切り替え
- 記事の構成・扱う論点・関連資料を確認する詳細ダイアログ
- 保存・既読状態のブラウザ内保存
- レスポンシブ表示

## データの更新

`data/articles.js` の配列に記事を追加し、`data/themes.js` のテーマ一覧を更新してください。本文は転載せず、タイトル・著者・媒体・日付・分類・原文URL・読書ナビゲーションだけを保持します。

外部依存のない静的サイトなので、GitHub Pagesなどの静的ホスティングでそのまま公開できます。
